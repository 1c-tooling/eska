# Адаптер метаданных для ядра BSL

Экспериментальная библиотека `eska-bsl-adapter` преобразует общую модель
метаданных ESKA в типы выбранного ядра BSL. Её зависимости закреплены отдельно;
основная библиотека проектов ESKA сохраняет независимость от ядра анализа.
Библиотека пока не публикуется и не входит в установленный комплект.

Первый преобразователь `common_module` принимает `ParsedObject` с загруженными
properties. UUID, имя, контекст выполнения, повторное использование результатов
и сведения заимствования переходят в `bsl_metadata::CommonModule` напрямую.
Отсутствующий флаг сохраняет отсутствие; `false` остаётся явным значением.
QName свойства проверяется по namespace и local name. Ошибки имеют координаты
в исходном XML/YAML. Недоступные свойства, неверные UUID, дубли и неизвестные
значения значимых флагов вызывают конкретную ошибку.

Конструирование модели не определяет доступность BSL-тела или полноту анализа
проекта. Эти сведения должен сохранять общий host. Заимствование в модели
проверяется для сохранения семантики ядра; профиль импорта расширений ESKA
по-прежнему не принят.

Исходный API закреплён на bsl-analyzer `9021ba0`; библиотека моделей используется
без IDE/LSP/MCP runtime. Для проверок нужен Rust; автоматические файловые
сценарии используют `ESKA_TEST_ROOT` в соседнем playground.
