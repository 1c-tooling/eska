# Загрузка статусов поддержки — 2026-10-24

При раскрытии «Общих модулей» список появлялся быстро, но статусы поддержки
ждали несколько секунд. Проверена отдельная копия реальной группы из buhmfo:
3808 модулей, исходный `Configuration.xml` и `ParentConfigurations.bin`.

## Причина и исправление

Explorer последовательно вызывал `metadata/source` для каждой строки, затем
ставил проверку поддержки в ту же очередь. Готовые статусы публиковались после
всех пакетов файлов и записи настроек защиты. Для группы потребовались
3809 запросов путей и 30 запросов поддержки.

В ESKA добавлен [Metadata API 1.25](../ide-protocol.md#api-125-пакетное-получение-поддержки-объектов):
`metadata/supportObjects` принимает до 128 ID. Правила, UUID и объявления
владельцев разрешает Rust-ядро. Общий XML читается один раз внутри пакета.
Заполнение существующего ограниченного кеша больше не вытесняет текущий
корневой дескриптор, нужный следующему пакету. Проверка текущих байтов сохранена.

Расширение объединяет ID нарисованных объектов, публикует каждый ответ сразу
и обновляет соответствующие строки. Очередь отображения не ждёт файловых
проверок и записи настроек. Смена поколения, отключение и завершение сессии
отбрасывают устаревшие ответы. Файловые разрешения остаются отдельной проверкой:
статус объекта не разрешает редактировать общий XML с запрещённым реквизитом.

## Замеры

Три чередующиеся пары до/после, свежие процессы и профили VSCodium 1.109.5,
установленные VSIX, Fedora 44, Intel Core i5-13420H, Rust 1.99.1, профиль `dist`.
Файловый кеш ОС и производный дисковый кеш не очищались. Во время серии сборки
и другие нагрузочные проверки не выполнялись. Языковой сервер отключён.

| Показатель, медиана | До | После |
| --- | ---: | ---: |
| Список 3808 объектов | 69,8 мс | 75,9 мс |
| Статусы первых 32 объектов | 3856,3 мс | 615,8 мс |
| Статусы всех 3808 объектов | 3857,3 мс | 1344,7 мс |
| Запросы для поддержки, без `metadata/children` | 3839 | 31 |
| Файловые политики, сохранённые ради отображения дерева | 3809 | 0 |

Первые статусы доступны в 6,3 раза быстрее, вся группа — в 2,9 раза.
Замер начинается перед получением списка группы; нативный `TreeView.reveal`
вызывает реальный provider. Измеряется публикация подтверждённых статусов
в Extension Host, а не момент отрисовки каждого пикселя. Первая порция включает
инициализацию поддержки в свежей сессии.

Копия содержит только общие модули, исходный root и правила поставщика;
неиспользуемые группы из root не копировались. Это замер раскрытия конкретной
группы, не всего запуска полной конфигурации. Хеши трёх перечисленных в
[машинном отчёте](../measurements/support-navigation-2026-10-24.json) исходных
файлов совпадают до и после каждой серии; полного хеширования всех файлов нет.
Отчёт содержит каждый запуск, агрегаты RPC, размеры пакетов и SHA-256 артефактов.
Сценарий воспроизводится `test/support-navigation-host.cjs` соседнего Explorer
через `test/run-host.mjs`; `ESKA_PERF_PROJECT` указывает на собственную копию
большого проекта в соседнем `eska-playground`.

## Проверки и совместимость

Прошли `cargo fmt --check`, `cargo check --workspace`, строгий Clippy для всех
targets/features, `cargo test --workspace` и rustdoc с запретом предупреждений:
1092 теста успешны, 12 ранее отключённых тестов пропущены. Проверки расширения:
TypeScript, 283 Node-теста успешны, 3 пропущены, содержимое VSIX проверено.

Нативная приёмка подтвердила независимость индикации от задержанной файловой
проверки, смену правил, сохранность dirty-текста, защиту модуля и общего XML,
пользовательские ограничения, два проекта с одинаковыми UUID, отключение
и повторное включение проверки. Установленный VSIX проверен на русском
и английском интерфейсе. Windows и macOS не запускались.

Backend 1.24 работает с новым расширением по прежнему пути: 3809 запросов
путей и 30 запросов поддержки. Для ускорения нужны обновлённые ESKA и Explorer.
Пользовательский профиль редактора и глобальная установка не менялись.

Изменения: ESKA `257a4c2 perf(project): Ускорено пакетное чтение поддержки объектов`;
Explorer `dda0ddc perf(explorer): Ускорен показ поддержки раскрытых объектов`.
