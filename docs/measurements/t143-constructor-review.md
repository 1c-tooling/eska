# T143 — Ревью и ускорение компактного конструктора

T143 завершена на Linux/VSCodium. Пользователь разрешил ревью, рефакторинг и
оптимизацию, затем согласовал медианы повторных операций на 48 полях:
открытие ≤400 мс, добавление поля ≤150 мс. Оба допуска выполнены.
Независимые части T134–T142 остаются принятыми; семантическая приёмка T142
и языковые возможности T136/T137 продолжают ожидать bsl-analyzer.

## Исправленные ошибки

1. **P1, ESKA:** текстовый узел `A OR B` внутри группы AND выдавал
   `(A OR B AND C)` вместо `(A OR B) AND C`. Узел теперь имеет собственные
   скобки; завершающий `//` не поглощает конец группы. Регрессия воспроизведена
   до исправления; проверены ru/en, CRLF, комментарии и точный no-op.
2. **P1, Explorer:** незавершённое `999` из редактора первого поля подставлялось
   во второе поле вместо его `2`. Удалён повторный снимок значений DOM;
   каждую форму заполняет её собственное состояние ввода.
3. **P2, Explorer:** «Выбрать всё» отмечало строки, но оставляло флажки снятыми.
   Восстановление старого DOM больше не перезаписывает актуальный выбор.
4. **P2, Explorer:** внутри поиска каждого контрола повторялся обход DOM-предков
   и соседей. Удалено воспроизведение значений, поиск соседей заменён проходом
   только по предыдущим элементам и пропускается для именованных узлов.

Ревью охватило добавленные операции конструктора, атомарную публикацию,
группы условий, модификаторы, связанный текст, RPC-ревизии и native lifecycle.
Изменения ограничены подтверждёнными ошибками и причиной задержки.

## Архитектура

Правила запроса, скобки, проверки и ревизии остаются в ESKA. Explorer хранит
только ввод формы, выбор, фокус и геометрию. Поиск доступного поля и выбранный
операнд привязаны к форме. Расширение не получило парсер, таблицу типов,
дублирующую модель запроса, постоянный cache или новую зависимость.
Metadata API остаётся 1.32; версии crate/package не изменены.

## Измерения

Одинаковые 48 полей, окно 1280×800, масштаб 100%, en, анализатор выключен.
На вариант — новый профиль, первое открытие отдельно, медиана следующих шести.
Все варианты используют действительно установленный VSIX. Базовый backend
в парном сравнении заморожен; финальный дополнительно содержит исправление AND/OR.

| Вариант | Открытие, медиана | Добавление поля, медиана |
| --- | ---: | ---: |
| До ревью | 1012.78 мс | 935.48 мс |
| После, тот же backend | 199.43 мс | 45.13 мс |
| После, финальный backend | 240.09 мс | 50.59 мс |
| Согласованный допуск | 400 мс | 150 мс |

В финальной серии первое открытие — 297,76 мс, первое добавление — 50,08 мс;
максимумы повторов — 300,04/54,15 мс.

В парной серии открытие быстрее в 5.1 раза,
добавление — в 20.7 раза.
Число RPC не изменилось: 8 при открытии, 5 при добавлении. Видны 18 полных строк;
ввод, фокус и выделение 3–7 сохранены во всех семи повторах каждого варианта.

Отдельный CPU-профиль добавления: ScriptDuration
1093.54 → 14.99 мс;
LayoutDuration 8.53 → 10.74 мс,
RecalcStyleDuration 5.39 → 6.70 мс.
Профиль подтвердил затраты JS/DOM. Бюджет проверен сериями без профайлера;
оставшееся время включает отрисовку, планирование и транспорт, а не только RPC.
В конце парных серий RSS backend — 16,45 → 16,57 MiB, extension host —
194,96 → 194,78 MiB, heap цели webview — 1,40 → 2,02 MiB. Первые операции
и все снимки сохранены в JSON; это не доказательство отсутствия долгосрочной утечки.

## Проверки

- Rust: fmt/check/clippy/rustdoc прошли; **1169 passed, 0 failed, 14 ignored**,
  35 наборов. Вспомогательных старых manifests в текущей ветке нет.
- Node и Bun: **347 passed, 3 skipped, 0 failed** каждый; TypeScript check и
  синтаксис изменённых JS/CJS прошли. Пропуски требуют внешних установок
  legacy backend или анализатора.
- **36 нативных наборов** ru/en: группы строк, условия, UNION, дерево пакета,
  модификаторы, связанный текст, preview/cancel/apply, исходный dirty-буфер,
  Undo/Redo, защита родителя, stale revision и перезапуск; также старый API 1.30
  и buhmfo с пятью расширениями при недоступном анализаторе.
- **24 сочетания** локали/темы/размера/масштаба: доступны команды и строки,
  сохраняются курсор, прокрутка, фильтр поля и состояние вложенной области.
  Снимок ru/high-contrast/900×650/150% осмотрен отдельно.
- 1С 8.3.27.2325: **29/29 запросов** текущего core реально выполнены
  на собственной минимальной ИБ. Три новых случая доказывают результат
  AND с текстовым OR слева/справа и с завершающим комментарием.
