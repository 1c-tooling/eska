# T143 — Скорость компактного конструктора

**Статус:** `DONE` на Linux/VSCodium. Последующим запросом пользователь разрешил
ревью, рефакторинг и оптимизацию. Согласованы медианы повторных операций
на 48 полях: открытие ≤400 мс, добавление поля ≤150 мс. Оба допуска выполнены.
Доработка bsl-analyzer не требуется; семантическая часть T142 остаётся открытой.

**Владелец:** Explorer — затраты представления; ESKA — операции, ревизии,
диапазоны и проверки. Исправление приоритета текстового условия сделано в ESKA.

## Исходные измерения T142

Одинаковый пример 48 полей, Linux/VSCodium, 1280×800 и 100%; медианы шести
повторных открытий после первого запуска:

| Сборка | Открытие | Добавление поля | Полных видимых строк |
| --- | ---: | ---: | ---: |
| Исходный интерфейс и API 1.30 | 176,65 мс | 35,30 мс | 5 |
| Компактный интерфейс и прежний API 1.30 | 264,15 мс | 124,04 мс | 21 |
| Компактные таблицы и API 1.32 | 1150,00 мс | 988,06 мс | 18 |

По первоначальному решению пользователя оптимизация была выделена отдельно;
допуск на том этапе не принимался. Исходные серии T142 сохранены без изменения.

## Результат ревью и оптимизации

Новая парная серия на том же замороженном backend: открытие
1012,78 → 199,43 мс; добавление 935,48 → 45,13 мс. Финальный backend с исправлением
группировки условий: **240,09/50,59 мс**. Число RPC осталось 8/5, видимых строк — 18;
ввод, фокус и выделение сохранились во всех семи повторах.

CPU-профиль подтвердил повторные обходы DOM при восстановлении значений.
Удалён дублирующий снимок контролов; форма и выбор строк имеют одного владельца.
Это также исправило перенос незавершённого ввода между полями и неверные флажки
«Выбрать всё». Обход соседей не выполняется для именованных узлов.
Доменные правила не перенесены в UI; новых зависимостей и cache нет.

В ESKA текстовый узел OR теперь сохраняет собственную группировку внутри AND;
закрывающая скобка не попадает в завершающий комментарий. Регрессия сначала
воспроизведена, затем проверена тестами и реальным выполнением 1С.

Пройдены полный Rust-набор (1169 тестов), Node/Bun (по 347), 36 нативных наборов
ru/en, 24 сочетания компоновки и 29 запросов на 1С 8.3.27.2325. Проверены старый
API 1.30, buhmfo с пятью расширениями, preview/cancel/apply, родитель, ревизии,
Undo/Redo, вложенные области и перезапуск. Windows/macOS/VS Code/Remote остаются
непроверенными. Глобальная установка не обновлялась; точные сборки и логи — в отчёте.
