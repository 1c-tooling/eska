# Общий ввод метаданных для анализа

`analysis_core::MetadataInputs` — общий контроллер сохранённого и несохранённого
YAML. Он доступен без default features, платформы, Git и IDE runtime. При
открытии читаются manifest/configuration и регистрируется полный объявленный
состав владельцев. Модели остальных владельцев остаются `Pending` до запроса.

`load_saved` и `apply_overlay` вызывают одну полную семантическую проекцию
`SourceReader::parse_metadata`. Значения, source hash и UTF-8 координаты
принадлежат одним точным bytes. Владелец содержит immutable `Arc` снимка;
сохранённый старый `Arc` не становится результатом для новой revision.
Изменение одного владельца не заменяет соседние модели и их revisions.

Каждый запрос изменения несёт текущую revision контроллера. Устаревший
запрос и повторная/меньшая версия открытого документа отклоняются до чтения
или изменения состояния. Revision локальна контроллеру: внешний протокол
обязан дополнительно проверять identity сессии/host. Счётчик не оборачивается.

Принятый неверный YAML заменяет текущую модель на `Unavailable` с исходной
структурированной ошибкой. Полностью прочитанный неверный текст всё равно
имеет source hash. Ошибка чтения, лимит и отмена также убирают старую модель;
непрочитанные полностью bytes не получают выдуманный hash. Контроллер не
пробует XML, прежний снимок, платформу или принятую базу.

Событие файловой системы не должно стирать черновик: `load_saved` отклоняет
обновление активного overlay. Только явный `close_overlay` переключает ввод
на текущий диск; отсутствие файла после закрытия становится ошибкой.
Изменение manifest/состава требует повторного открытия контроллера.

`InputSummary.metadata_input_complete` означает, что прочитаны все объявленные
владельцы и в их проекции нет recoverable issues. Это **не** полнота типов
адаптера BSL, не успешность семантического анализа и не проверка платформой.
`Pending`, `Unavailable` и recoverable diagnostics остаются различимыми.

`InputRequest` ограничивает bytes одного документа перед выделением памяти
для disk read и перед parse overlay. Лимит можно уменьшать относительно
64 MiB формата, но нельзя повышать. `Cancellation` проверяется до и после
ограниченной работы; она пока не прерывает parser посреди одного документа.
Это не предел RSS, общего количества моделей или кеша Salsa. Общие бюджеты
и отмена запросов ядра остаются частью EF-18.

Проверки используют собственные каталоги playground: паритет saved/overlay,
invalid → unavailable → восстановление, поздние requests/document versions,
сохранность черновика, соседние Arc/revision, лимиты, отмену, неполную проекцию,
identity, undeclared paths, symlinks и переполнение revision. Реальный consumer
[canonical input](canonical-inputs.md) передаёт состояние контроллера в Salsa;
недоступный владелец очищает canonical MDO, а BSL completion перестаёт
показывать реквизит старого черновика. Поставка analyzer/check ещё не готова.
