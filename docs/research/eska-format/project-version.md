# Приёмка схем версии проекта — T83

T83 — `DONE` для configuration/extension, Designer XML 2.20 на 1С
8.3.27.2325. [Результаты](project-version-results.json) фиксируют независимый
CF/CFE цикл, проверки отказов и Rust gates. Источник версии внешних объектов
остаётся [T84](../../roadmap/10-delivery-and-integrations.md).

## Модель и настройка

Общий тип хранит ровно три или четыре компонента. `x.y.z` использует числовое
ядро SemVer: младшие компоненты при bump сбрасываются к нулю, ведущие нули
отклоняются. `x.y.z.build` сохраняет правила T25 и исходную ширину чисел.
Суффиксы и prerelease не поддерживаются; переполнение отклоняется до записи.

Необязательный `[version].scheme` выбирает `x.y.z` или `x.y.z.build`.
Настройка workspace наследуется member, явная настройка member имеет приоритет.
Без настройки схема определяется корректным текущим номером. Несоответствие
настройке — ошибка; настройка не хранит копию номера и не преобразует его.
Первый номер и смена схемы задаются явно в источнике и настройке.

Прежний четырёхкомпонентный JSON остаётся schema 1 без новых полей.
Три компонента используют schema 2 с `version_scheme`; mixed workspace —
schema 2 со схемой каждого member. JSON не зависит от языка. Build manifest
сохраняет прежний envelope и точную строку версии.

## Платформенный цикл

В собственных изолированных проектах проверены `version`, `version bump minor`,
`eska-build build` и свежая выгрузка через `eska new --from`. Матрица включает
обе локали human output и независимую проверку версии/контрольной суммы manifest.

| Артефакт | Схема | До bump | После bump и свежей выгрузки |
|---|---|---|---|
| CF | `x.y.z` | `1.2.3` | `1.3.0` |
| CF | `x.y.z.build` | `01.02.003.0004` | `01.03.001.0001` |
| CFE | `x.y.z` | `1.2.3` | `1.3.0` |
| CFE | `x.y.z.build` | `01.02.003.0004` | `01.03.001.0001` |

Каждая исходная правка заменяет только текст прямого `Properties/Version`.
Остальные bytes исходного descriptor совпали. Нативный dump сохранил точную
строку, включая нули и число компонентов. Пустая версия исходного CFE была
задана явно в собственной fixture до bump; автоматического выбора первого
номера нет. Всего прошли 26 положительных этапов.

При несовпадении схемы чтение, bump и сборка отказаны на RU/EN. Сборка не
запускала платформу; предыдущие CF/manifest и исходный descriptor остались
побайтно прежними. Политика проверяется до импорта и на immutable snapshot.

## Проверки и границы

Прошли fmt, check, strict Clippy, обычные и all-feature тесты, Rustdoc с
запретом предупреждений, минимальная сборка core и соответствующие SDK gates.
Результат: 716 unit, 575 integration, 44 project-tool, 10 build-tool и
359 SDK тестов; 24 ранее отключённых теста сохраняют прежний статус.
Проверены BOM/CRLF, нули, overflow, строгая настройка, наследование workspace,
совместимость JSON и сохранность опубликованной пары artifact/manifest.

Приёмка ограничена проверенными платформой и Designer profile. Исполнение
расширения в клиенте здесь не проверялось. EPF/ERF и BSL-источник версии — T84;
адаптер версии ESKA — EF-14; автоматическая подготовка релиза — T56/T32.
Версия crate и release pipeline не менялись.
