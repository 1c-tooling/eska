# Большой CF: открытие и 500 изменений одного реквизита

На Linux x86_64 проверена отдельная копия настоящей Designer XML конфигурации
профиля 2.20: 8820 native files, 372254706 bytes. Production `eska-project import
--layout queries` завершился с exit 0 за 61.435 s. Получено 8141 authoring files
и 3617 declared owners. Исходная выгрузка сохранила bytes, mode и mtime.
Платформа и клиент 1С в этом прогоне не запускались.

## Что измерено

Использован замороженный release `eska-analyzer` из среза `79c7f53`
[CF/CFE composition](analyzer-cf-cfe-composition.md), SDK 0.0.0 с source core
0.14.2. Тот же harness и тот же проект проверены на release checkpoint
`2deec7f` для сопоставления. Проект здесь standalone CF; большой настроенный
состав CF/CFE этим замером не проверен.

В каждой локали новый child сначала проходит initialize и перечисляет owners
страницами по 200. Все owners остаются pending, source reserve равен нулю:
регистрация дерева не выдаётся за загрузку моделей. Затем читается один owning
YAML справочника. Его inline attribute выбирается по current typed metadata;
`metadata/locate` подтверждает Name range и hash реального YAML.

Один открытый BSL draft обращается к объекту этого справочника. После первой
completion выполняются десять повторов без изменения входов. Затем 500 раз
меняется только Name выбранного реквизита в полном YAML overlay. После каждого
ACK проверяется текущий hash и completion: новое имя присутствует, предыдущее
и сохранённое отсутствуют. BSL draft остаётся неизменным. Close восстанавливает
saved field и текущий disk BSL. Все 22117 файлов проекта, включая accepted base,
сохраняют bytes/mtime. На RU/EN source и native heap counters совпадают во всех
точках измерения.

## Результат текущей сборки

Таймер cold включает `Popen` и initialize. Это новый процесс с обычным системным
файловым кешем; кеш ОС не очищался. Возможно пересечение с независимой приёмкой
Explorer. Времена показывают этот прогон, без обещания производительности.

| Операция | RU/EN, ms |
| --- | ---: |
| Запуск и initialize | 156–172 |
| Все страницы owners | 60–62 |
| Первое чтение выбранного YAML | 40–42 |
| Первая completion | 32–34 |
| Медиана completion без изменения | 0.7–0.9 |
| Медиана YAML update + completion | 35.9–36.3 |

Медиана обновления на baseline — 35.6–36.6 ms. Разница этих одиночных прогонов
не интерпретируется как ускорение или регрессия.

RSS снимается независимо через `/proc` child после initialize, первого запроса
и каждых 50 изменений. Source reserve и неполная native heap estimate
сохраняются отдельно. Полный набор samples находится в
[обезличенном отчёте](large-cf-current-input-results.json).

RSS после первого запроса — 92972–93216 KiB, после 500-го изменения —
95252–95512 KiB. Source reserve после последнего изменения — 163937 bytes,
native heap estimate — 4424324 bytes. Эти значения относятся к выбранным
зависимостям; неполная heap estimate не заменяет измерение RSS.

Загружены только выбранные зависимости; все модели большого проекта не
подготавливались. Source-byte quota не ограничивает весь heap/RSS процесса.
Этот прогон не измеряет открытие установленного Explorer и не подтверждает
полноту BSL/SDBL, большой CFE или весь MVP.

## Отказ и сохранность черновика

Новые процессы с `--max-retained-source-bytes 0` принимают owning YAML и BSL
version 37 как current unavailable с `analysis_source_budget_exceeded`.
Прежний hash очищен, reserve равен нулю, editor version сохранена. Повтор той
же версии отклонён без изменения snapshot. Клиент сохраняет полные тексты;
replay в новый child с обычной квотой восстанавливает точные hashes и current
reads/diagnostics. Это пройдено на RU/EN для обеих сборок, без записи проекта.
Четыре измерительных и восемь quota/replay children штатно завершились.

Другой, более крупный native input был явно отклонён импортом с
`source_form_id_duplicate`: два элемента одной child-items list имели один ID.
Частичный destination не опубликован, исходник сохранён. Это проверка отказа;
валидность этого входа в платформе и производительность анализа по нему
не выводятся из данного результата. Повторяющийся ID не исправлялся.
