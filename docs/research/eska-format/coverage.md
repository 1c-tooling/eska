# Покрытие первого профиля

Профиль `designer-2.20-configuration` принимает обычный корень `Configuration`
в `http://v8.1c.ru/8.3/MDClasses`. Расширение, `ExternalDataProcessor`,
`ExternalReport`, другой XML-профиль и неизвестный класс метаданных дают явный
отказ. Режим совместимости и версия проекта сохраняются, не нормализуются.

| Конструкция | Представление ESKA | Обратное правило | Первая разрешённая правка |
|---|---|---|---|
| Корень и основной объект известного `MetadataKind` | Тип, родной UUID, имя, свойства, упорядоченный состав | Тот же namespace, kind и UUID | Свойства из подтверждённого набора |
| `Name` | Строка и identity владельца | Исходное имя | Переименование отдельно; изменение имени без плана отклоняется |
| `Comment`, `Version` | Строка с явным состоянием | Точное значение, включая ведущие нули | Изменение существующего значения; версия не обязана иметь известную bump-стратегию |
| `Synonym` | Упорядоченные языковые значения | Исходные language keys и локальный namespace | Изменение существующего текста |
| Отсутствие, пустой элемент, `xsi:nil`, explicit default | Различимые состояния | Исходное состояние | Только по контракту конкретного свойства; nil не равен отсутствию |
| Числа, даты, bool, enum и compound type вне первого набора | Сохранённое значение с исходным контекстом | Точные байты/лексика, без float и вывода defaults | Пока отказ |
| `ChildObjects` с inline UUID | Вложенные объекты внутри YAML владельца | Исходная вложенность и порядок | Свойство части при разрешении поддержки |
| `ChildObjects` со ссылкой на отдельный descriptor | Упорядоченная декларация и вложенное описание | Исходный descriptor и связь с владельцем | Свойство описания; create/delete/rename отдельно |
| `InternalInfo`, generated type/value IDs | Сохранённая служебная часть | Те же UUID, роли и порядок | Отказ до отдельного правила |
| Неизвестное свойство, локальный `xmlns`, QName в значении | Непрозрачная часть с владельцем, slot и namespace-контекстом | В исходное место без потери контекста | Небезопасная соседняя структурная правка отклоняется |
| Форма и её внутренние ID | Исходный ресурс и описание у владельца | Побайтовый payload | BSL отдельно; typed form — EF-12 |
| BSL и бинарные модули | Отдельные файлы с владельцем и ролью | Байты, BOM, EOL и наличие файла | BSL при разрешении поддержки |
| Макеты, СКД, картинки, справка, Rights/Predefined | Отдельные исходные ресурсы | Байты и относительные связи | Typed writer отдельно; поддержка проверяет ресурс целиком |
| Нативные правила и CF поставщиков | Принятые зависимости, вне отображаемых свойств | Точные принятые данные | Только явное принятие базы, не правка YAML |
| Файл вне объявленного состава | Явная preserved/unreferenced запись | Тот же путь, не включать в `ChildObjects` | Не активировать обходом каталогов |
| `ConfigDumpInfo.xml` | Служебные данные происхождения | Состав/ID сохраняются; изменённые версии отдельно от исходников | Не использовать как поддержку или обход полного экспорта |

Классы берутся из единого реестра `MetadataKind::ALL`; одинаковая синтаксическая
оболочка не означает приёмку специфических операций каждого класса. Публичный
корпус проверяет configuration/catalog/common module/form и вложенные
attribute/tabular section; C1 расширяет файловую приёмку на наблюдавшиеся классы.

Каждая строка различает чтение, сохранение и изменение. Полный файловый цикл
может сохранить неподдержанную для редактирования часть. Невозможность доказать
обратное восстановление означает отказ, а не пропуск данных.
