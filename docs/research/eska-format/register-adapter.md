# Модели регистров в адаптере ESKA

`eska-bsl-adapter::register` принимает общий `ParsedDescriptor` из XML или YAML.
Модель содержит измерения, ресурсы, реквизиты, их UUID/типы, периодичность,
режим записи и настройки итогов. Неявные стандартные поля приходят из
закреплённого каталога `bsl-platform`; nil UUID относится только к таким полям.
Настоящие объявления сохраняют собственные UUID.

[Первый результат](register-adapter-results.json) включает fmt/check/strict Clippy/test/
Rustdoc, 19 unit и три файловых теста. Черновик YAML меняет режим записи и тип
измерения; ошибочное значение адресуется в текущем YAML, сохранённый файл и
предыдущая модель остаются прежними. Неполный descriptor не становится готовым.

| Корпус | Совпали поддержанные модели | Поля этих моделей | Не поддержаны |
|---|---:|---:|---:|
| C1 | 228 | 2 030 | 0 |
| C2 | 1 435 | 16 329 | 29 |
| C3 | 1 930 | 23 360 | 33 |

Сравниваются полные модели главных дескрипторов регистров с нативным reader ядра.
Формы, модули, права и другие метаданные не входят в этот audit. Реальные корпуса
содержат регистры сведений/накопления/бухгалтерии; регистр расчёта проверен
на модельном fixture. Запуск read-only, PATH пустой, XML не экспортируется.
Время в JSON относится к dev-сборке и не является замером production host.

В первой проверке C2/C3 обнаружены допустимые периодичности `Quarter`/`Year`: 9/20 и 10/23.
Значения сверены через `bsl-analyzer-reference.syntax_help` для
`ПериодичностьРегистраСведений`. Их нет в исходном
[enum закреплённого ядра](https://github.com/1c-tooling/bsl-analyzer/blob/9021ba07471eee8a2614bed2105a2c8699f60780/crates/bsl-metadata/src/register.rs#L140).
В этой ревизии нативный parser терял значение и не выдавал виртуальные таблицы
срезов; прежний адаптер возвращал `UnsupportedPropertyValue` с исходными
координатами. Пустое значение не подставлялось. Первый audit C2/C3 дал явное
неполное покрытие и exit 2; исторический JSON сохранён.

[Локальное расширение ядра](kernel-integration.md) теперь сохраняет обе
периодичности и используется адаптером. Полный host и analyzer/check CLI
по-прежнему не завершены.
